延迟随负载非线性增长，在真实系统里通常对应下面几类**可区分**的机制。它们各自有独立的观测判据，所以能靠数据分开，而不是靠猜：

1. **排队效应（最普遍）**
   - 机制：到达率接近服务能力时，等待时间按 1/(1−ρ) 发散。
   - 判据：延迟随 QPS 的曲线在某个利用率附近急剧上翘；CPU/线程池利用率同步接近饱和；此时延迟对 QPS 的导数发散。
   - 需要的材料：QPS–延迟曲线、资源利用率时间序列。

2. **资源池耗尽（连接池、线程池、文件描述符）**
   - 机制：池满后请求排队等连接，等待时间阶跃式上升。
   - 判据：池占用率打到上限；出现获取连接超时；延迟分布出现第二个峰。
   - 需要的材料：池指标、超时日志。

3. **锁竞争 / 串行化点**
   - 机制：临界区随并发增加，争用导致吞吐下降、延迟超线性上升。
   - 判据：并发升高时 CPU 利用率不升反降；锁等待时间占比上升；profiler 显示热点在锁上。
   - 需要的材料：profiler / 火焰图、锁等待指标。

4. **GC / 内存压力**
   - 机制：分配速率升高触发更频繁 GC，STW 暂停叠加。
   - 判据：延迟尖刺与 GC 暂停时间对齐；堆增长与分配速率相关。
   - 需要的材料：GC 日志、堆指标。

5. **重试风暴 / 级联**
   - 机制：超时触发重试，重试又加重负载，正反馈。
   - 判据：重试率随错误率上升；总请求量超过入口 QPS。
   - 需要的材料：重试计数、入口 vs 后端请求量对比。

6. **缓存失效 / 命中率下降**
   - 机制：负载升高改变访问分布，命中率下降，回源放大。
   - 判据：命中率与延迟负相关；回源 QPS 放大。
   - 需要的材料：缓存命中率、回源量。

这六类的**观测特征互不相同**，所以只要给我数据，就能排除掉大部分，而不是六选一地猜。
